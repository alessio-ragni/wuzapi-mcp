# Configuration

Everything is set in `.env`, next to `docker-compose.yml`. `scripts/init-env.sh` creates it from
`.env.example` with random secrets and your computer's time zone, and refuses to overwrite an
existing one. After changing `.env`, apply it with:

```bash
docker compose up -d
```

`.env` holds secrets: it is ignored by git and created readable by you only. Never commit it.

## Secrets

Generated by `init-env.sh`; there is normally no reason to touch them.

| Setting | What it is |
|---|---|
| `WUZAPI_ADMIN_TOKEN` | Lets wuzapi-mcp create and delete the WuzAPI user that holds your session. |
| `WUZAPI_GLOBAL_ENCRYPTION_KEY` | Encrypts secrets inside WuzAPI's database. Exactly 32 characters. **Never change it after the first start**: WuzAPI could no longer read what it encrypted. |
| `WUZAPI_GLOBAL_HMAC_KEY` | Signs every event WuzAPI sends to wuzapi-mcp; anything unsigned is refused. At least 32 characters. |
| `WUZAPI_USER_TOKEN` | The token of the WuzAPI user that holds your WhatsApp session. |

## WhatsApp

| Setting | Default | What it does |
|---|---|---|
| `WUZAPI_USER_NAME` | `owner` | Name of that WuzAPI user. Cosmetic. |
| `SESSION_DEVICE_NAME` | `wuzapi-mcp` | How the device is called on your phone under *Linked devices*. Applies at the next link. |
| `WUZAPI_SYNC_DAYS` | `365` | Days of history the phone is asked for when it links (0–365). Applies at the next link. The phone decides what it actually sends. |
| `WUZAPI_HISTORY_PER_CHAT` | `0` | Messages WuzAPI keeps itself, per chat. Leave it at 0: wuzapi-mcp's archive is the copy that matters, and WuzAPI 1.1.0 cannot store history on SQLite anyway (see [troubleshooting](troubleshooting.md#known-wuzapi-issues)). |

## Ports and image

| Setting | Default | What it does |
|---|---|---|
| `MCP_HOST_PORT` | `8091` | The page and the MCP endpoint: `http://127.0.0.1:8091`. Bound to your computer only. |
| `WUZAPI_HOST_PORT` | `8090` | WuzAPI's own API, for debugging. Bound to your computer only. |
| `WUZAPI_MCP_VERSION` | `latest` | Which published image of wuzapi-mcp to run. Set a version such as `0.1.0` to stay on it. |
| `TZ` | your time zone | Time zone used for the dates Claude sees, e.g. `Europe/Rome`. |

If you change `MCP_HOST_PORT`, use the new port in the `claude mcp add` line as well.

## Voice transcription

Off by default: `transcribe_voice` then answers that it is off. To turn it on, choose a provider
and give it what it needs, then `docker compose up -d`.

| `TRANSCRIPTION_PROVIDER` | Also set | Notes |
|---|---|---|
| `off` | — | Default. |
| `openai` | `OPENAI_API_KEY` | Whisper through the OpenAI API. Billed by OpenAI per minute of audio. |
| `elevenlabs` | `ELEVENLABS_API_KEY` | ElevenLabs Scribe. |
| `whisper-local` | `WHISPER_URL` | Any server that speaks the OpenAI transcription API, e.g. whisper.cpp's server or faster-whisper-server. Give the base URL including `/v1`. A server running on the same computer is reached from Docker as `http://host.docker.internal:<port>/v1`. |

The voice note is sent to the provider you choose; with `whisper-local` it never leaves your
machine.

## Files

These are set in `docker-compose.yml`, not in `.env`:

- your home folder is mounted **read-only**, at the same path, so `send_file` and `send_voice`
  accept the paths you would type yourself. Files outside it cannot be sent;
- `~/Downloads/wuzapi-mcp` is mounted writable: `download_media` saves there.

To use other folders, change the two `volumes` lines and the matching `FILES_ROOT` and
`DOWNLOADS_DIR` under the `wuzapi-mcp` service.
